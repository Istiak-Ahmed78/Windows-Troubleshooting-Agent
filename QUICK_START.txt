📋 WHAT IS THIS?
────────────────
An intelligent Windows troubleshooting agent that diagnoses PC issues
and provides smart solutions through a chat interface.

🚀 QUICK INSTALLATION
──────────────────────

Windows Users - Option 1 (Easiest):
  1. Double-click: run.bat
  2. Wait for dependencies to install
  3. Application launches automatically

Windows Users - Option 2 (Manual):
  1. Open Command Prompt
  2. cd C:\path\to\troubleshooting_ai_agent
  3. pip install -r requirements.txt
  4. python main.py

PowerShell Users:
  powershell -ExecutionPolicy Bypass -File launch.ps1

🔧 COMMON ISSUES & SOLUTIONS
──────────────────────────────

Issue: Python not found
Solution: Install Python 3.8+ from python.org
         Make sure to check "Add Python to PATH"

Issue: Module not found error
Solution: Run "pip install -r requirements.txt"
         Or try: pip install customtkinter psutil

Issue: Permission denied error
Solution: Run Command Prompt/PowerShell as Administrator
         Right-click > Run as Administrator

Issue: Temperature not showing
Solution: May need admin privileges
         Not critical for other diagnostics
         Run as Administrator for full features
