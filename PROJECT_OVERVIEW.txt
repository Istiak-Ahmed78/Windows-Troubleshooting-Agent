🛠️ INSTALLATION & CONFIGURATION
══════════════════════════════════════════════════════════════════════════

System Requirements:
  • Windows 7, 8, 10, or 11
  • Python 3.8 or higher
  • 150 MB free disk space
  • Administrator access (recommended)

Python Dependencies:
  • customtkinter >= 5.2.0    (GUI framework)
  • psutil >= 5.9.6           (System monitoring)
  • wmi >= 1.5.1              (Windows WMI)
  • pywin32 >= 305            (Windows API)

Installation Methods:
  1. Automatic:    Double-click run.bat
  2. PowerShell:   Launch.ps1
  3. Manual:       pip install -r requirements.txt
  4. Direct:       python main.py

Customization:
  • Edit config.py for colors, thresholds, recommendations
  • Modify GUI_CONFIG for interface customization
  • Adjust DIAGNOSTICS_THRESHOLDS for sensitivity
  • Extend with advanced_diagnostics.py features
